# 草稿保存与图标更新设计

日期：2026-08-14

## 目标

解决草稿在首次离开并返回时显示旧内容的问题，并保证用户以任何方式离开草稿时，最新输入都会保存。将草稿工具和右上角页面入口替换为本地打包的官方 Material Symbols Rounded Filled 图标。

## 草稿保存与读取

### 离开草稿

所有会离开草稿编辑器的操作共用一个异步离开入口：日记主页、新建条目、搜索、回收站、设置、取消、发布，以及关闭桌面程序。

该入口按以下顺序执行：

1. 等待编辑器中的图片或音乐任务完成。
2. 立即保存编辑器当前值，绕过 500 毫秒自动保存等待。
3. 更新草稿查询缓存并使其失效。
4. 保存成功后才切换页面或允许桌面窗口关闭。

保存失败时，停留在编辑器并显示已有的失败提示；不切换页面、不关闭窗口，以避免内容丢失。

### 返回草稿

草稿编辑器首次显示缓存数据时，会继续请求服务器上的最新草稿；收到同一草稿 ID 的新内容后，编辑器必须同步其值，而不是只以 ID 作为重置条件。每次成功保存也会把服务端返回的草稿写入查询缓存。

这样首次返回草稿即可显示刚保存的内容，不需要再次离开、返回。

### 关闭桌面程序

Electron 主进程在窗口关闭前向渲染进程请求草稿保存完成。渲染进程只在保存成功或没有活跃草稿时确认关闭。保存失败时取消本次关闭，并保留恢复提示。

## 图标

### 来源与交付

使用 Google 官方 Material Symbols Rounded 的 Filled 变体。字体或 SVG 资源会随应用本地打包，运行时不请求 Google Fonts 或任何网络资源。

### 图标映射

| 位置 | 图标 | 英文提示 |
| --- | --- | --- |
| 日记主页 | `home` | `Diary` |
| 新建条目 | `edit_square` | `New entry` |
| 搜索 | `search` | `Search` |
| 回收站 | `delete` | `Trash` |
| 设置 | `settings` | `Settings` |
| 插入图片 | `add_photo_alternate` | `Insert image` |
| 附加音乐 | `library_music` | `Attach MP3` |
| 预览 | `visibility` | `Toggle preview` |

右上角五个入口只显示图标；草稿编辑器保持图片、音乐、预览的现有行为，切换到预览时仍隐藏图片和音乐按钮。所有按钮保留英文无障碍名称和悬停提示。

### 颜色

图标默认使用界面灰褐色，当前页面入口使用赭金色，悬停及键盘聚焦使用正文色。所有颜色使用已有主题变量，因此深色和浅色模式均自动适配。

## 验证

测试覆盖：

- 从每一种页面入口离开草稿时，先保存再切换。
- 关闭桌面窗口时等待保存；保存失败时保持窗口打开。
- 首次返回草稿即显示最新保存内容。
- 图标按钮没有可见文字，但保留正确的英文无障碍名称、提示、当前页状态和主题颜色规则。
- 类型检查、完整测试与 Windows 打包验证。
